# ISO/TR 9241-100:2010 - Introduction to Standards Related to Software Ergonomics#

## Scope
Technical Report introducing the structure and numbering scheme of ISO 9241 series (Ergonomics of human-system interaction). Helps potential users (ergonomists, usability professionals, designers, project managers, workers, consumers, procurers, certification bodies) identify relevant software-ergonomics standards.

## Key Terms
- **Software ergonomics**: Application of ergonomics to software aspects of interactive systems (human-centred design).
- **Usability**: Extent to which product can be used by specified users to achieve specified goals with effectiveness, efficiency, satisfaction in specified context of use.
- **Context of use**: Users, tasks, equipment (hardware/software), physical/social environments.
- **Effectiveness**: Accuracy/completeness with which users achieve goals.
- **Efficiency**: Resources expended relative to effectiveness.
- **Satisfaction**: Freedom from discomfort + positive attitudes toward product use.
- **Accessibility**: Extent to which system is usable by people with widest range of capabilities.
- **Interactive system**: Combination of hardware/software receiving user input and providing output.

## Structure of ISO 9241 Series ("100" Subseries)
### General Standards on Software Ergonomics (ISO 9241-110 to ISO 9241-119)
- **ISO 9241-110**: Dialogue principles (7 principles: suitability for task, self-descriptiveness, conformity with user expectations, suitability for learning, controllability, error tolerance, suitability for individualization).
- **ISO 9241-111 to 119**: Reserved for general guidance (upon revision, content of ISO 14915-1 will be integrated here).

### Input, Output and Interaction (ISO 9241-120 to ISO 9241-129)
- **ISO 9241-120 to 128**: Reserved for input/output/interaction guidance.
- **ISO 9241-129**: Guidance on software individualization (determining where individualization is appropriate, selecting mechanisms, using all types, specific types, combinations).

### Performance Support (ISO 9241-130 to ISO 9241-139)
- **ISO 9241-130 to 139**: Reserved for performance support (user guidance, learning support, tutorials, instructions).

### Interaction Techniques (ISO 9241-140 to ISO 9241-149)
- **ISO 9241-140 to 149**: Reserved for interaction techniques (menus, commands, direct manipulation, forms, natural language, question/answer dialogues).

### Topic-Specific Standards (ISO 9241-150 to ISO 9241-159)
- **ISO 9241-151**: Guidance on WWW user interfaces.
- **ISO 9241-152**: Interpersonal communication.
- **ISO 9241-153**: Virtual reality.
- **ISO 9241-154**: Interactive voice response (IVR) applications (under preparation).
- **ISO 9241-155 to 159**: Reserved for topic-specific guidance.

### User Interface Control Components (ISO 9241-160 to ISO 9241-169)
- **ISO 9241-160 to 169**: Reserved for UI control components (controlling groups of information, lists, media controls, interface control components).

### Cross-Topic Guidance on Accessibility (ISO 9241-170 to ISO 9241-179)
- **ISO 9241-171**: Guidance on software accessibility.
- **ISO 9241-172 to 179**: Reserved for accessibility guidance.

### Numbers Reserved for Future Use (ISO 9241-180 to 189; ISO 9241-190 to 199)
- Reserved for future software-ergonomics standards.

## Human-Centred Design Standards (ISO 9241-200 to ISO 9241-299)
- **ISO 9241-210**: Human-centred design for interactive systems (replaces ISO 13407).
- **ISO 9241-220**: Human-centred life cycle processes.
- **ISO 9241-230**: Human-centred design methods.
- **ISO/TR 18529**: Process descriptions for human-centred design.
- **ISO/TR 16982**: Usability methods supporting human-centred design.
- **ISO/PAS 18152**: Process assessment of human-system issues.

## General Standards Relevant to Software Ergonomics
- **ISO 6385**: Ergonomic principles in design of work systems.
- **ISO 9241-11**: Guidance on usability (defines usability, context of use, measures).
- **ISO 9241-20**: Accessibility guidelines for ICT equipment/services.

## Other Standards with Software Ergonomics Guidance
- **ISO 14915-1**: Multimedia user interfaces - Design principles and framework (to be integrated into ISO 9241-110 subseries).
- **ISO 14915-2**: Multimedia user interfaces - Multimedia navigation and control.
- **ISO 14915-3**: Multimedia user interfaces - Media selection and combination.
- **ISO/IEC TR 29138-1**: Accessibility considerations for people with disabilities - User needs summary.
- **ISO/TR 22411**: Applying ISO/IEC Guide 71 to address needs of older persons and persons with disabilities.

## Common Industry Format (CIF) for Usability
- **ISO/IEC TR 25060**: General framework for usability-related information.
- **ISO/IEC TR 25062**: Usability test reports.

## Relationship to Other Standards
- Part of **ISO 9241** series (Ergonomics of human-system interaction).
- Builds on **ISO 6385** (Ergonomic principles for work systems).
- References **ISO 9241-11** (Usability guidance), **ISO 9241-20** (Accessibility guidelines).
- Companion: **ISO 9241-210** (Human-centred design), **ISO/TR 16982** (Usability methods), **ISO/TR 18529** (HCD process descriptions), **ISO/PAS 18152** (Process assessment).
- Related: **ISO 13407** (replaced by ISO 9241-210), **ISO 14915** (Multimedia interfaces).

## When to Use
- Navigating ISO 9241 series to find relevant standards.
- Selecting software ergonomics standards for projects.
- Understanding structure of software ergonomics standards.
- Identifying applicable standards for ergonomists, designers, project managers.
- Planning human-centred design processes.
- Aligning with software ergonomics best practices.

## Benefits of Software Ergonomics Standards
- Prevent usability problems: unnecessary steps, misleading info, insufficient UI info, unexpected system response, navigational limitations, inefficient error recovery.
- Increase accessibility for users with widest range of capabilities.
- Enhance user productivity, satisfaction, well-being.
- Reduce training/support costs, legal risks.
- Support compliance with accessibility regulations.

## Overview of ISO 9241 Subseries
### ISO 9241-300: Electronic Visual Displays
- Introduction, terminology, requirements, test methods (laboratory, field, compliance).
### ISO 9241-400: Physical Input Devices
- Principles, requirements, design criteria, selection procedures, test methods.
### ISO 9241-500: Workplace Ergonomics
- Workstation layout, work environment, control centres.
### ISO 9241-700: Control Rooms
- Introduction, design principles, arrangement, layout, displays, controls, evaluation.
### ISO 9241-900: Tactile and Haptic Interactions
- Framework, guidance, interactions in multimodal environments, evaluation, public device interfaces.
