# ISO 9241-420:2011 - Selection of Physical Input Devices#

## Scope
Provides guidance for selecting physical input devices (keyboards, mice, pucks, joysticks, trackballs, touchpads, tablets/overlays, touchscreens, styli/light pens) based on usability-related properties. Applies to user organizations and systems integrators tailoring systems for given contexts of use.

## Key Terms
- **Input device**: User-controlled device transmitting information to a system.
- **Task primitive**: Fundamental action (pointing, selecting, dragging, tracing, code entry) associated with non-keyboard input device use.
- **Index of difficulty**: Measure of user precision required for a task: `ID = log2(d/w + 1)` (d=distance to target, w=target width).
- **Appropriateness**: Application of usability concept to entities combined for a specific purpose.
- **Effectiveness**: Accuracy/completeness with which users achieve specified goals.
- **Efficiency**: Resources expended relative to effectiveness.
- **Satisfaction**: Freedom from discomfort + positive user attitudes.
- **Intended user population**: Group of humans for which a product/workstation is designed.

## Procedures for Selecting Equipment
### 4.1 Rationale
Selection procedures enable finding suitable tool(s) for given task(s), user(s), software. Based on ISO 9241-11 usability concept: product has no inherent usability; usability depends on specified context of use (users, tasks, environment).

### 4.2 Objectives for Selection Procedures
- Determine if device is suitable for intended use (fit for purpose).
- Compare devices of same kind for given context.
- Test acceptability of device for tasks outside intended use.
- Determine minimum quality (resolution, size) for required task.
- Determine acceptability of replacement devices.
- Determine workplace requirements for input device combination.

## Performance Criterion (Clause 5)
Input device or combination shall be usable for task: user achieves satisfactory performance (effectiveness, efficiency) with acceptable effort/satisfaction.

## Methods and Aids for Selection (Clause 6)
### 6.1 Task Analysis
Analyze overall user task at workstation to provide:
- Task primitives to be supported.
- Critical task primitive(s) with overriding importance (e.g., character input).
- Rank order of task primitive relevance for context.
- Restrictions for available support surfaces (size, quality, arrangement).
- Mutual exclusion effects (e.g., two devices needing same space in reach envelope).
- Required effectiveness level (e.g., minimum screen area accessible via pointing device <4 pixels).
- Required efficiency level (e.g., selecting/dragging with one finger only).

### 6.2 Selection Based on Product Description
Use tables in Annex H to check correspondence with generic requirements from ISO 9241-410:
- Tables H.1-H.4: Compact keyboards (appropriateness, operability, controllability, biomechanical load).
- Tables H.5-H.12: Compact keyboards functional/other properties.
- Tables H.13-H.24: Full-size keyboards correspondence.
- Tables H.25-H.39: Mice correspondence.
- Tables H.40-H.54: Pucks correspondence.
- Tables H.55-H.69: Joysticks correspondence.
- Tables H.70-H.84: Trackballs correspondence.
- Tables H.85-H.99: Touchpads correspondence.
- Tables H.100-H.115: Tablets/overlays correspondence.
- Tables H.116-H.129: Styli/light pens correspondence.
- Tables H.130-H.141: Touch-sensitive screens correspondence.

### 6.3 User Tests
Apply when product description lacks sufficient information. Recommended for:
- Devices with mutual exclusion issues.
- Drivers/settings for new context of use.
- Alternative workplace arrangements.
- Comparing same-type devices.
- Critical task primitive dedicated device selection.
Include satisfaction assessment via interviews/questionnaires (Annex D).

### 6.4 Selection Based on Dominant Task Primitive(s)
Select device optimized for task primitive with overriding importance:
- **Code entry**: Full-size keyboard (C1 compatibility, 19mm key spacing).
- **Pointing (accurate)**: Mouse/trackball (C1 resolution, index of difficulty >6).
- **Pointing (rapid)**: Mouse (C2 resolution, index 4-6).
- **Dragging**: Mouse/trackball with adequate button design.
- **Tracing**: Tablet/overlay with stylus (low index of difficulty ≤3).

### 6.5 Field Assessment of Input Devices
Assess devices in actual workplace:
- Use Annex B (tracing test), Annex C (dragging test), Annex E (one-direction tapping), Annex F (multi-directional tapping), Annex G (mobile text entry) for standardized assessments.
- Evaluate comfort via Annex D (comfort assessment).
- Compare against product description and user test results.

## Annexes (Test Methods)
- **Annex A**: ISO 9241 series overview.
- **Annex B**: Tracing test (task primitive: tracing).
- **Annex C**: Dragging test (task primitive: dragging).
- **Annex D**: Comfort assessment (user comfort with device).
- **Annex E**: One-direction tapping test (task primitive: selecting).
- **Annex F**: Multi-directional tapping test (task primitive: pointing).
- **Annex G**: Mobile text entry test (hand-held keyboards).
- **Annex H**: Selection tables for all device types (normative).

## When to Use
- Selecting input devices for specific tasks/user populations.
- Comparing devices for given context of use.
- Assessing device acceptability for new tasks.
- Determining workplace requirements for device combinations.
- Evaluating input device usability in field settings.
- Aligning with ISO 9241-400/410.

## Relationship to Other Standards
- Part of **ISO 9241-400** subseries (Physical input devices).

- Companion: **ISO/TS 9241-411** (Laboratory test methods for physical input devices).
- References **ISO 9241-11** (Usability definition), **ISO 6385** (Ergonomic principles).
