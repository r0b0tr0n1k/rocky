# ISO 704:2009 Terminology Work - Principles and Methods

Follow ISO 704:2009 "Terminology work - Principles and methods" for all terminology work.

## Core Concepts

### Objects
- Anything perceived or conceived (concrete, abstract, imaginary)
- Described by properties; abstracted into concepts

### Concepts
- **General concept**: Depicts set of objects with common properties (designated by **terms**)
- **Individual concept**: Depicts single object or unique composition (designated by **appellations**)
- Intension = set of characteristics; Extension = set of objects

### Designations
1. **Terms**: Designate general concepts (monosemy preferred: 1 term → 1 concept)
2. **Appellations**: Designate individual concepts (proper names in specific subject fields)
3. **Symbols**: Non-linguistic representations (icons, alphanumeric codes, SI units)

## Concept Relations (Model using tree/rake diagrams)

1. **Generic relations** (inheritance): Superordinate → Specific concepts
   - Specific concept inherits all characteristics of superordinate
   - Example: pointing device → computer mouse → mechanical/optomechanical/optical mouse
   
2. **Partitive relations** (whole-parts): Comprehensive concept → Partitive concepts
   - No inheritance between parts and whole
   - Example: computer mouse → mouse ball, button, circuit board, x-axis roller
   
3. **Associative relations** (thematic): Non-hierarchical connections
   - Examples: action-actor, product-composition, cause-effect, container-contained

## Concept Systems
- **Generic**: All concepts linked by generic relations
- **Partitive**: All concepts linked by partitive relations  
- **Associative**: All concepts linked by associative relations
- **Mixed**: Combination of relation types

## Definition Writing (Intensional = preferred)

### Format
`[Entry term] [superordinate concept] [delimiting characteristics]`

Examples:
- mechanical mouse: computer mouse in which movements are detected by rollers and a ball
- optical mouse: computer mouse in which movements are detected by light (LED)
- mouse ball: spherical part on underside of mechanical/optomechanical mouse whose movement controls pointer

### Rules
- Begin with superordinate concept (inherited characteristics not repeated)
- Include only delimiting characteristics
- Use substitution principle: definition can replace designation in discourse
- Avoid: circularity, inaccuracy (too broad/narrow), negatives
- For individual concepts: describe parts if comprehensive concept

## Term Formation Principles

1. **Transparency**: Meaning inferable from parts (e.g. thermal noise > Johnson noise)
2. **Consistency**: Follow established patterns (e.g. synthetic fabrics end in "-on")
3. **Appropriateness**: Avoid confusing connotations (e.g. install wizard → installation wizard)
4. **Linguistic economy**: Concise forms (e.g. e-mail > electronic mail)
5. **Derivability**: Allow derivatives (e.g. herb → herbal, herbalist)
6. **Linguistic correctness**: Follow morphological/n phonological norms
7. **Preference for native language**: Over direct loans

### Methods
- **Neoterms**: Derivation (phosphor + -ous), Compounding (high-definition television), Abbreviation (UN, laser)
- **Existing forms**: Conversion (output n. → output v.), Terminologization (virus med. → virus comp. sci.)
- **Translingual**: Direct loan (raster), Loan translation (Weltanschauung → worldview)

## Appellations (Individual Concepts)

Categories:
- Bodies/institutions (World Health Organization)
- Meetings (Kyoto Conference 2005)
- Position titles (Prime Minister, Pope John Paul II)
- Programs/products (Marshall Plan, Honda®)
- Honors (Nobel Peace Prize 2001)
- Social phenomena (WWII, Remembrance Day)
- Scientific phenomena (Halley's Comet, Saturn)
- Toponyms (Paris, France vs. Paris, Michigan)
- Methods/procedures (Purity Test)
- Document names (GATT, NAFTA)

### Rules
- Keep original language form; add jurisdictional markers if ambiguous
- Singular/plural grammar reflects individual concept status
- Record former appellations and temporal changes

## Supplementary Information (beyond definition)

- **Notes**: Non-delimiting characteristics, optional parts
- **Concept descriptions**: Wide-ranging info (historical, instances)
- **Encyclopedic descriptions**: Goes beyond definition with detailed knowledge
- **Explanations**: How concept operates (operational definitions)
- **Defining contexts**: Cited text allowing meaning deduction

## Deficient Definitions to Avoid
- **Circular**: Uses term being defined (e.g. evergreen tree = tree with evergreen foliage)
- **Inaccurate**: Too broad/narrow (e.g. optomechanical mouse = computer mouse with ball → includes mechanical mice)
- **Negative**: Defines by what it is NOT (e.g. deciduous tree = tree other than evergreen)

## Term Harmonization
- **Preferred term**: Recommended by technical committee
- **Admitted term**: Acceptable synonym
- **Deprecated term**: Rejected (e.g. fireproof → fire-resistant)

## Notation Conventions
- Generic relations: `1.`, `1.1`, `1.2` (inheritance)
- Partitive relations: `1-`, `1-1`, `1-2` (whole-parts)
- Associative relations: Line with arrowheads (thematic connections)
- Concepts: Single quotes `'concept'`
- Designations: **Bold** `**term**`
- Characteristics: Underlined
- ISO 1087-1 terms: *Italics*
