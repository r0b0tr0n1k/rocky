# Outbox Dead Letter Queue

Events that fail 3 delivery attempts are moved to the **dead-letter queue** with `status='dead_letter'`. These require manual intervention.

## Finding Dead Letters

```sql
-- List all dead-letter events
SELECT id, type, aggregate_type, aggregate_id, error_message, created_at
FROM outbox_events
WHERE status = 'dead_letter'
ORDER BY created_at DESC;

-- Count by event type
SELECT type, COUNT(*) as count
FROM outbox_events
WHERE status = 'dead_letter'
GROUP BY type
ORDER BY count DESC;
```

## Common Failure Patterns

| Error Pattern | Root Cause | Fix |
|--------------|------------|-----|
| `No handler registered for event type` | New event type emitted but handler not added | Add handler in `OutboxEventHandlers` |
| `FOREIGN KEY violation` | Referenced record deleted before handler runs | Add `ON DELETE CASCADE` or validate in handler |
| `NOT NULL constraint violation` | Handler expects field missing from payload | Fix publisher to include required fields |
| `Timeout` | Handler takes >30s (DB lock, external API) | Optimize handler or increase timeout |

## Remediation

### Option 1: Retry After Fix

```sql
-- Reset event to pending for retry
UPDATE outbox_events
SET status = 'pending',
    delivery_attempts = 0,
    next_attempt_at = now()
WHERE id = 'event-uuid';
```

### Option 2: Discard Event

```sql
-- If event is no longer relevant, mark as completed
UPDATE outbox_events
SET status = 'completed',
    processed_at = now(),
    error_message = 'Discarded by operator — stale event'
WHERE id = 'event-uuid';
```

### Option 3: Reprocess with Modified Handler

If the handler logic was fixed, reset the event:

```sql
UPDATE outbox_events
SET status = 'pending',
    delivery_attempts = 0,
    next_attempt_at = now(),
    error_message = NULL
WHERE id = 'event-uuid';
```

## Preventing Dead Letters

1. **Register all emitted event types** — `OutboxEventHandlers.registerDefaultHandlers()` must cover every `type` emitted by services
2. **Make handlers idempotent** — safe to retry without side effects
3. **Validate payloads** — handler should check required fields before action
4. **Add timeouts** — external API calls should have 10s timeout
