# Managing Animals

Search, view details, and update animal records in Rocky.

## When to Do This

Use the animal management features when you need to:

- Find a specific animal by ear tag code
- View an animal's complete history
- Update animal details (e.g., weight, notes)
- Verify that an animal's record is accurate before a movement

## Requirements

- The animal must already be registered in the system
- You need the ear tag code or at least part of it to search

## Step-by-Step

### Search for an Animal

1. Open the app → **Animals** tab
2. Tap the search icon
3. Enter the ear tag code or a partial code
4. Tap a result to open the animal's profile

### View Animal Details

The animal profile shows:

- Ear tag code and type
- Species, breed, date of birth
- Sex
- Current farm location
- Movement history
- Health records
- Passport status (for cattle)

### Update Animal Information

1. Open the animal's profile
2. Tap **Edit**
3. Update the fields you need to change (weight, notes, etc.)
4. Tap **Save**

> **Note:** Some fields (ear tag code, date of birth, species) cannot be changed once registered. If you made an error, see [Corrections](/user-guide/corrections).

## What Happens Next

- Changes are saved and synced to the national registry
- The animal's history is updated with a note of the change
- You can continue with other workflows (movements, health, etc.)
