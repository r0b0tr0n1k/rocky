# Seized / Lost Passport

Report a lost, damaged, or seized passport and request a replacement.

## When to Do This

Report a passport issue when:

- The passport has been lost
- The passport is damaged and unreadable
- The passport has been seized by authorities
- The animal has been sold and the passport needs transfer

## Requirements

- The animal must be registered in the system
- You need to know the passport number (if available)
- A reason for the seizure or loss must be provided

## Step-by-Step

### Report a Lost or Damaged Passport

1. Open the app → **Passports** tab
2. Find the animal's passport
3. Tap **Report Issue**
4. Select the reason: **Lost**, **Damaged**, or **Seized**
5. Enter the date of loss or seizure
6. Add any relevant details
7. Confirm the report

### Request a Reprint

1. After reporting, tap **Request Reprint**
2. Confirm the request
3. The new passport will be issued

> **Tip:** A seized passport can be either reprinted (if the animal is still alive) or cancelled (if the animal has died or been exported).

## What Happens Next

- The passport status changes to **Seized**
- If a reprint is requested, a new passport is issued with status **Reprinted** → **Active**
- If no reprint is needed, the passport is **Cancelled**
- The animal's record is updated with the new passport status
