# App Navigation

This page explains the Rocky mobile app layout and how to navigate between sections.

## When to Do This

Read this page when you first install the app to understand where to find each feature.

## App Tabs

The Rocky mobile app is organised into the following tabs:

| Tab | What You Can Do |
|-----|-----------------|
| **Animals** | View registered animals, register births, manage ear tags |
| **Movements** | Record and view animal movements |
| **Health** | Record vaccinations, treatments, lab tests, and disease reports |
| **Passports** | View and request cattle passports |
| **Account** | Manage your profile, settings, and notifications |

## Offline Indicator

When you lose internet connection, the app shows an offline indicator at the top of the screen. You can continue working offline — data syncs automatically when the connection is restored.

## Step-by-Step

### Navigate Between Tabs

1. Open the Rocky app
2. Tap any tab at the bottom of the screen to switch sections
3. The active tab is highlighted

### Search for an Animal

1. Go to the **Animals** tab
2. Tap the search icon
3. Enter the ear tag code or part of the animal name
4. Tap a result to view details

### Check Sync Status

1. Tap the **Account** tab
2. The sync status is displayed at the top of the page
3. A green checkmark means everything is synced

## What Happens Next

- You can now navigate the app confidently
- Each tab gives you access to the workflows described in this guide
