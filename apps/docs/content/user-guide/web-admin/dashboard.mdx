# Dashboard

The web admin dashboard provides an overview of key metrics and system status.

## When to Do This

Use the dashboard when you need a quick overview of system activity, pending tasks, or compliance status.

## What You See

| Metric | Description |
|--------|-------------|
| Total farms | Number of registered farms |
| Total animals | Number of registered animals |
| Pending movements | Movements awaiting recording |
| Upcoming inspections | Scheduled inspections |
| Pending corrections | Correction requests awaiting approval |
| Sync status | Last successful data sync time |

## Step-by-Step

1. Log in to the **Web Admin** panel
2. The **Dashboard** is the default view
3. Review the key metrics
4. Click any metric to drill down into details
5. Use the date range filter to view historical data

## What Happens Next

- The dashboard updates in real time
- Click through to any section for detailed management
- Export reports as needed for compliance documentation
