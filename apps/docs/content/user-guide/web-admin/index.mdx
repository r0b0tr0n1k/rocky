# Web Admin Guide

This section is for administrators who manage the Rocky system through the web admin panel. The web admin panel provides farm and user management, system configuration, and compliance monitoring tools.

## Who Should Use This Guide

- **System administrators** managing farms and users
- **Veterinary authorities** running inspections and risk analysis
- **Compliance officers** monitoring audit logs and regulatory adherence

## What You Can Do

- Monitor key metrics on the **Dashboard**
- Create and manage **farms** and keepers
- Manage **users** and permissions
- Review **audit logs** for compliance
- Configure **system settings** and feature flags
