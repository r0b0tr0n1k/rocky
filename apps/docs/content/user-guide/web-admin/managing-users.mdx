# Managing Users & Permissions

Manage user accounts, roles, and permissions in the web admin panel.

## When to Do This

Manage users when:

- A new user needs access to the system
- A user's role or permissions need updating
- A user leaves the organisation and needs to be deactivated

## Roles and Permissions

| Role | Permissions |
|------|-------------|
| **Super Admin** | Full system access, all management features |
| **Admin** | Farm and user management, inspections, reports |
| **Veterinarian** | Health records, inspections, disease reporting |
| **Farmer** | Own farm management, animal registration, movements |

## Step-by-Step

### Add a New User

1. Log in to the **Web Admin** panel
2. Go to **Users** → **Add User**
3. Enter the user's name, email, and role
4. Assign the user to one or more farms (if applicable)
5. The user will receive an invitation email

### Update User Role

1. Go to **Users** → search for the user
2. Click the user name to open details
3. Click **Edit**
4. Change the role as needed
5. Save changes

### Deactivate a User

1. Go to **Users** → search for the user
2. Click the user name
3. Click **Deactivate**
4. Confirm the deactivation

## What Happens Next

- Users receive email notifications for account changes
- Role changes take effect immediately
- Deactivated users cannot log in until reactivated
