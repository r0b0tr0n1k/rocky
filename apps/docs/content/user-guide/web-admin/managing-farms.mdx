# Managing Farms

Create, update, and manage farm records and keepers in the web admin panel.

## When to Do This

Manage farms when:

- A new farm needs to be registered in the system
- Farm details need updating
- A farm keeper changes or needs reassignment

## Requirements

- Admin access to the web panel
- Farm registration details (name, location, registration number)
- Keeper identification details

## Step-by-Step

### Create a New Farm

1. Log in to the **Web Admin** panel
2. Go to **Farms** → **Add Farm**
3. Enter the farm name and registration number
4. Enter the farm address and location coordinates
5. Select the farm type (livestock, dairy, mixed)
6. Assign a farm keeper
7. Save the record

### Update Farm Details

1. Go to **Farms** → search for the farm
2. Click the farm name to open details
3. Click **Edit**
4. Update the necessary fields
5. Save changes

### Manage Keepers

1. Go to **Farms** → open a farm record
2. Go to the **Keepers** tab
3. Add or remove keepers as needed
4. Set the primary keeper

## What Happens Next

- The farm is registered in the national system
- The keeper can access the farm through the mobile app
- Farm details are available for inspections and reporting
