# Audit & Compliance

Review the audit log and compliance tools in the web admin panel.

## When to Do This

Use the audit tools when you need to:

- Review changes made to farm and animal records
- Verify compliance with regulatory requirements
- Investigate discrepancies in the data
- Prepare for audits or inspections

## What You Can See

| Audit Log Type | Records |
|----------------|---------|
| Animal changes | All modifications to animal records |
| Movement history | All recorded animal movements |
| User actions | Login, role changes, permission updates |
| System changes | Configuration and parameter modifications |
| Correction requests | All submitted and approved corrections |

## Step-by-Step

### View Audit Log

1. Log in to the **Web Admin** panel
2. Go to **Compliance** → **Audit Log**
3. Use the filters to narrow down results:
   - Date range
   - Entity type (animal, farm, user)
   - Action type (create, update, delete)
   - User who performed the action
4. Click any entry to view details

### Export Audit Data

1. Apply the desired filters
2. Click **Export**
3. Select the export format (CSV, PDF)
4. The report is downloaded

## What Happens Next

- Audit logs are immutable — they cannot be modified or deleted
- Exported reports can be used for external audits
- The audit trail supports regulatory compliance documentation
