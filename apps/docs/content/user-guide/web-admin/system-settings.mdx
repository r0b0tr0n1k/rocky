# System Settings

Configure system-wide settings, feature flags, and parameters in the web admin panel.

## When to Do This

Modify system settings when you need to:

- Enable or disable system features
- Configure regulatory parameters
- Adjust deadlines and thresholds
- Manage system-wide notification templates

## What You Can Configure

| Setting | Description |
|---------|-------------|
| Feature flags | Enable or disable in-development features |
| Regulatory parameters | Movement deadlines, tagging deadlines, etc. |
| Notification templates | Customise email and push notification content |
| Risk analysis parameters | Weights and thresholds for inspection selection |
| System parameters | General configuration values |

## Step-by-Step

1. Log in to the **Web Admin** panel
2. Go to **Settings**
3. Select the settings category:
   - **Features** — Toggle feature flags on or off
   - **Regulatory** — Adjust deadlines and thresholds
   - **Notifications** — Edit notification templates
   - **Parameters** — Configure general system parameters
4. Make your changes
5. Save the configuration

> **Warning:** Changes to regulatory parameters may affect compliance deadlines. Review the impact before applying changes.

## What Happens Next

- Changes take effect immediately
- The system uses the updated configuration for new records
- Existing records are not retroactively affected
- All configuration changes are logged in the audit trail
