# Inspection System Overview

This section explains how the Rocky inspection system works, how farms are selected for inspection, and what happens during an on-spot visit.

## What You Can Do

- **Understand risk analysis** — Learn how farms are selected for inspection
- **Prepare for inspections** — Know what happens during an on-spot visit

## How It Works

The inspection system follows an annual cycle:

1. At the start of each year, a risk analysis selects farms for inspection
2. A random 10% of farms are selected, weighted by risk factors
3. Selected farms receive a scheduled on-spot inspection
4. The veterinarian conducts the inspection and records the results
