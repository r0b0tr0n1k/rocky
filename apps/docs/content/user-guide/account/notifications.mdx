# Notifications & Alerts

Configure which notifications and alerts you receive from the Rocky system.

## When to Do This

Set up your notification preferences when you first create your account, or update them whenever you want to change which alerts you receive.

## Types of Notifications

| Notification Type | Description | Default |
|-------------------|-------------|---------|
| Movement deadline reminder | Alert when a movement deadline approaches | On |
| Birth registration reminder | Reminder to register a new birth | On |
| Ear tag order update | Status change on your ear tag orders | On |
| Inspection notification | Your farm has been selected for inspection | On |
| Notifiable disease alert | A notifiable disease has been reported nearby | On |
| Passport status change | Passport issued, seized, or cancelled | On |
| Correction request update | Status change on a correction request | On |
| Sync warning | Offline data needs attention | On |

## Step-by-Step

### Configure Notifications

1. Open the app → **Account** tab
2. Tap **Notifications**
3. Toggle each notification type on or off
4. Changes are saved automatically

### View Notification History

1. Open the app → **Account** tab
2. Tap **Notifications**
3. Tap **History** to see past notifications

## What Happens Next

- You will receive notifications based on your preferences
- Notifications appear in the app and as push notifications (if enabled)
- You can change your preferences at any time
