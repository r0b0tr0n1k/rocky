# Corrections

When and how to correct errors in the Rocky system.

## When to Do This

Submit a correction request when you discover an error in your animal records, such as:

- Incorrect ear tag code
- Wrong date of birth
- Incorrect species or breed
- Wrong movement date
- Duplicate registration

## Types of Corrections

| Type | Description | Approval Needed |
|------|-------------|-----------------|
| **A Priori** | Correction before the data is submitted to the national registry | No |
| **A Posteriori** | Correction after the data has been submitted | Yes (admin) |

## Step-by-Step

### Submit a Correction Request

1. Open the app → **Animals** tab
2. Find the animal with the error
3. Tap **Report Error**
4. Select the field that needs correction
5. Enter the correct value
6. Provide a reason for the correction
7. Submit the request

### Track Correction Status

1. Go to **Account** → **Corrections**
2. View the status of your correction requests
3. Status options: **Pending**, **Approved**, **Rejected**

## What Happens Next

- A priori corrections are applied immediately
- A posteriori corrections require admin approval
- The correction is logged in the audit trail
- The animal's record is updated
