# Vaccinations

Record a vaccination administered to an animal.

## When to Do This

Record a vaccination whenever you or a veterinarian administers a vaccine to an animal. This includes routine vaccinations and campaign-based vaccination drives.

## Requirements

- The animal must be registered in the system
- You need the vaccine batch number and expiry date
- The vaccine must be registered in the system's vaccine catalogue

## Step-by-Step

1. Open the app → **Health** tab
2. Tap **+** (new record)
3. Select **Vaccination**
4. Search for the animal by ear tag code
5. Select the vaccine from the catalogue
6. Enter the batch number and expiry date
7. Enter the dosage and administration method
8. Enter the vaccination date
9. Add any relevant notes (e.g., adverse reactions)
10. Confirm the record

> **Tip:** Always check the vaccine batch is not expired before administering. The system will warn you if the batch has expired.

## What Happens Next

- The vaccination is added to the animal's health record
- The system updates the vaccine batch inventory
- Future vaccinations can reference this record for booster scheduling
