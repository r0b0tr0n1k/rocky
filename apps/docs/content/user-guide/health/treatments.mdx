# Treatments & Diagnoses

Record a treatment or diagnosis for an animal.

## When to Do This

Record a treatment whenever an animal receives medical attention, including:

- Diagnosis of an illness or condition
- Administration of medication
- Surgical procedures
- Follow-up care

## Requirements

- The animal must be registered in the system
- A veterinarian should confirm the diagnosis and prescribe treatment
- You need the medication details (name, dosage, batch number)

## Step-by-Step

1. Open the app → **Health** tab
2. Tap **+** (new record)
3. Select **Treatment**
4. Search for the animal by ear tag code
5. Enter the diagnosis
6. Select the condition from the list (or enter a custom diagnosis)
7. Enter the treatment details:
   - Medication name
   - Dosage and administration method
   - Batch number and expiry date
   - Treatment date and duration
8. Enter the treating veterinarian's name (if applicable)
9. Add any relevant notes
10. Confirm the record

> **Tip:** If the diagnosed condition is a notifiable disease, use the [Notifiable Diseases](/user-guide/health/notifiable-diseases) workflow instead — do not record it as a regular treatment.

## What Happens Next

- The treatment is added to the animal's health record
- The system updates medication inventory
- Follow-up treatments can reference this record
- If a notifiable disease was suspected, the farm is flagged for inspection
