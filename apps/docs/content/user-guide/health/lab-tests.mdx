# Lab Tests

Request a laboratory test and view the results.

## When to Do This

Request a lab test when you need diagnostic confirmation for a suspected condition, or as part of routine disease surveillance.

## Requirements

- The animal must be registered in the system
- You need to know which test is required
- A sample must be collected and sent to a registered laboratory

## Step-by-Step

### Request a Test

1. Open the app → **Health** tab
2. Tap **+** (new record)
3. Select **Lab Test**
4. Search for the animal by ear tag code
5. Select the test type from the list
6. Enter the sample collection date
7. Select the destination laboratory
8. Add any relevant notes (e.g., symptoms, suspect condition)
9. Confirm the request

### View Results

1. Go to the animal's health record
2. The lab test status is displayed
3. Tap the test to view detailed results
4. Results include: test name, result value, reference range, interpretation

> **Tip:** Lab test results may take several days to process. The system will notify you when results are available.

## What Happens Next

- The lab receives the test request
- Results are uploaded to the system when available
- The animal's health record is updated with the results
- If the test confirms a notifiable disease, the system triggers an alert
