# Tutorials

Start here. Pick your surface:

- **Backend contributor** — [Get Started](/get-started) walks from `git clone` to your first tRPC router + domain service, grounded in the [Diamond Seal](/ADR/0011-diamond-seal-layer-boundaries) and [Execution Pipeline](/ADR/0003-execution-pipeline-stages).
- **Frontend / Mobile contributor** — once the API is up, the [Client Surface Inventory](/ADR/0034-client-surface-inventory) + [Offline-first Sync](/ADR/0036-offline-sync-architecture) ADRs are your map.
- **Architect / reviewer** — read the [Documentation Architecture](/ADR/0052-documentation-architecture) ADR first, then the decision corpus under `/ADR`.

> Every architecture decision is recorded as an ADR under `/ADR`. New work starts with a Proposed ADR; see [ADR-0033](/ADR/0033-frontend-mobile-adr-standard) for the house standard + `ADR-TEMPLATE.md`.
