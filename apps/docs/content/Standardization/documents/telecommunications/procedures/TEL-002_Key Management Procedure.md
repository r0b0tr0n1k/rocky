# Key Management Procedure

Law on Personal Data Protection of Republic of North Macedonia

## 1. Purpose

This procedure defines the step-by-step process for implementing and maintaining security controls in accordance with Article 36 of the Law on Personal Data Protection and Article 28 of Law No. 124/2024 on Personal Data Protection.

## 2. Scope

This procedure applies to:

- **Personnel:** All employees, contractors, and third parties with access to organizational systems
- **Systems:** All information systems, networks, and physical facilities
- **Activities:** Implementation, monitoring, and maintenance of security controls

## 3. Prerequisites

Before starting this procedure, ensure:

- Security policy has been reviewed and approved by management
- Required technical resources are available
- Personnel have received appropriate training
- Risk assessment has been conducted

## 4. Procedure Steps

### Step 1: Risk Assessment

**Responsible:** Security Manager

**Actions:**
1. Conduct comprehensive risk assessment of systems and data
2. Identify potential vulnerabilities and threats
3. Assess impact of security incidents
4. Document findings in risk register

**Output:** Completed risk assessment report

**Timeframe:** Within 30 days of policy implementation

### Step 2: Control Implementation

**Responsible:** IT Operations Team

**Actions:**
1. Install and configure technical security controls
2. Implement physical security measures
3. Establish administrative controls and procedures
4. Document all implemented controls

**Output:** Configured security controls and documentation

**Timeframe:** Within 60 days of risk assessment

### Step 3: Testing and Validation

**Responsible:** Security Manager

**Actions:**
1. Conduct penetration testing
2. Verify control effectiveness
3. Test incident response procedures
4. Document test results

**Output:** Test results and validation report

**Timeframe:** Quarterly or after major changes

### Step 4: Monitoring and Review

**Responsible:** Security Manager

**Actions:**
1. Implement continuous monitoring
2. Review security logs regularly
3. Assess control effectiveness
4. Update procedures as needed

**Output:** Monitoring reports and procedure updates

**Timeframe:** Ongoing

## 5. Error Handling

If an error or incident occurs:

1. **Immediate Response:** Contain the incident and minimize impact
2. **Investigation:** Determine root cause and scope
3. **Documentation:** Record all actions taken and decisions made
4. **Reporting:** Report to supervisor and Data Protection Officer
5. **Remediation:** Implement corrective measures and prevent recurrence

## 6. Quality Control

Before completing each procedure step, verify:

- All required actions have been completed
- Documentation is complete and accurate
- Controls meet security requirements
- Test results are documented
- Stakeholders are informed of results

## 7. Records and Documentation

Maintain the following records:

- Risk assessment reports (retained 5 years)
- Control implementation logs (retained 5 years)
- Test results and validation reports (retained 5 years)
- Monitoring reports (retained 3 years)
- Incident reports (retained 10 years)
- Training records (retained 3 years)

Records must be retained for the specified periods and stored securely.
