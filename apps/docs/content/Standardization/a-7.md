# ISO/IEC 27001:2022 — Annex A.7 (normative) — Physical controls

## A.7.1

**Physical security perimeters**

Security perimeters shall be defined and used to protect areas that contain information and other associated assets.
  
### Keywords

- a.7.1
- physical security
- security perimeters
- protect communications
  
### Key Points

- Security perimeters shall be defined and used to protect areas that contain information and other associated assets
  
### Compliance Checklist

- [ ] Security measures must be appropriate to risks
- [ ] Security measures must be documented
- [ ] Security incidents must be reported
