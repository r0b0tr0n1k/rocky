## 2.2 Change Approval Process

### For Routine Changes

1. Request submitted to IT manager
2. Impact assessment completed
3. Change scheduled during maintenance window
4. Applied and tested
5. Documented in this log

### For Emergency Changes

1. Immediate action taken to resolve issue
2. DPO notified within 1 hour
3. Change documented in this log within 4 hours
4. Post-incident review within 24 hours
