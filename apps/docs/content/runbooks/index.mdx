# Runbooks

Operational procedures for standing the system up and keeping it running.

- [Run the Stack Remotely (compose)](/runbooks/run-stack-remote) — server deploy with the single `DATABASE_URL`, bundled vs external DB
- [DB Recreate & RLS](/runbooks/db-recreate) — `db-recreate.sh`, the `check_function_bodies` trick, RLS `$N` fix
- [Deploy (EAS)](/runbooks/deploy) — cloud discipline, `@gocenik/rocky`
- [Manage Environment Variables](/runbooks/env-config) — dev-on-PC vs docker-compose env models, secrets hygiene, worktree ports, troubleshooting
- [Sign PDF documents](/runbooks/sign-pdf-documents) — signer env + interim dev cert (ADR-0082)
- [Veterinary & Sanitary Smoke Test](/runbooks/veterinary-sanitary-smoke-test) — seed fake data + watch the ADR-0092 zone draw
- [VM Prep & Domain](/runbooks/vm-prep) — remote VM standup + the Cloudflare/domain precondition

These are the *operate* counterpart to `/how-to` (build) and `/ADR` (decide).
