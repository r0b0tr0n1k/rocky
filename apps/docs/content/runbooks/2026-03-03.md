## Findings (verified in-tree, this session)

1. **Two divergent kebab implementations** — `RowActions` (`components/shared/row-actions.tsx`)
   and `RowActionMenu` (`components/shared/action-dialog.tsx`) — with inconsistent item
   ordering, labels, and iconography across ~11 table-column files.
   (ISO 9241-143 consistency; 9241-110 §4.4 self-descriptiveness.)
2. **Generic kebab label** — row kebabs render `aria-label="Actions"` with no per-row meaning.
   (ISO 9241-110 §4.4.)
3. **Sidebar active state is color-only** — `SidebarMenuButton` `isActive` sets only a
   background; no left-accent / weight distinction. Fails "more than color alone".
   (ISO 9241-161 §6, 9241-12.)
4. **DataTable density bypasses the route toggle** — `data-table.tsx` hard-codes
   `densityCompactClass` on the whole `<Table>`, ignoring per-column intent and the
   `useTableDensity()` context default. (ISO 9241-110 §4.2 suitability / individualization.)
5. **`ActionDialog` does not focus the first field on open.** (ISO 9241-171, M4 RHF.)
6. **`ActionDialog` has no error-summary surface** for a failed mutation.
   (ISO 9241-110 §4.2, M6.)

## Decisions (this session)

- **D1 (T02 / M2):** sidebar active state gains a left-edge inset accent
  (`--sidebar-primary` via `boxShadow`), distinct from color alone through weight + accent
  - focus-visible ring. No new `.mdx` design authority introduced; `@rocky/ui` stays source.
- **D2 (T03 / M3):** canonical `RowMenu` (`components/shared/row-menu.tsx`) with
  `kind: "navigation" | "action" | "destructive" | "dialog"`; stable primary-first ordering;
  real per-row `label`; consistent iconography (destructive → `AlertTriangle`). It internally
  splits navigation/href vs action/mutation vs dialog.
- **D3 (T04 / M4):** destructive `RowMenu` items route through **one** path — `AlertDialog`
  confirm (reusing `ActionDialog`'s `alert`) + sonner **Undo** toast (iso-7 pattern).
  `RowActions` and `RowActionMenu` become thin adapters over `RowMenu`; **zero call-site changes**.
- **D4 (T05 / M1):** DataTable density reads `columnDef.meta?.density` per column;
  `effective = meta.density ?? routeDensity`. Per-cell `!py-1.5 text-xs` reproduces the prior
  compact look exactly (zero regression); columns may opt into compact independently of the toggle.
- **D5 (T06 / M4):** `ActionDialog` focuses the first field on open
  (`requestAnimationFrame` + `contentRef` query).
- **D6 (T07 / M6):** `ActionDialog` gains optional `error?: ReactNode` → destructive `Alert`
  above the form. *(Form skeleton deferred — `ActionDialog` is non-fetching, so it has no
  loading state to skeleton.)*
- **D7 (T08 / M3):** ~25 call sites migrated to real per-row `label` + primary-first ordering
  (delegated to an `admin-bot` subagent, scoped to `apps/web`).
