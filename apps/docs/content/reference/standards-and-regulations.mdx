# Standards, Regulations & Laws Reference

This page catalogs **every external standard, EU regulation/directive, technical specification, and national law** referenced across the Rocky codebase and documentation, together with the file where each is cited so sources can be verified. It was compiled from a repo-wide sweep of `AGENTS.md`, `packages/`, and `apps/docs/content` (`ADR/`, `compliance/`, `Standardization/`).

> **How to read it:** the *Mentioned in* column points at the actual repo source (ADR, compliance doc, or code path). Click those to verify the cite. The *Subject* column is the instrument's generally-known scope — confirm against the linked source before relying on it.
>
> The project's **own** binding decisions (the `ADR-NNNN` files) are listed in the final section — they are internal "standards", not external law.
