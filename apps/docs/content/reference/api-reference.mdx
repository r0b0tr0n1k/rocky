# API Reference

Auto-generated from TypeScript types via Nextra's `TSDoc` component (`nextra/tsdoc`), which turns `type` / `interface` / `function` source into property, parameter, and return tables. This is the apex of the repo's NoDrift ideology: the doc *is* the type, so drift is impossible by construction.

## How it works

<TSDoc
  definition={generateDefinition({
    code: `
import type { TSDoc } from 'nextra/tsdoc'
type MyProps = React.ComponentProps<typeof TSDoc>
export default MyProps`
  })}
/>

The `code` string is parsed by `ts-morph` at build time (Server-Component only). To document the **real** surface, point `generateDefinition` at a type from `@rocky/trpc` (e.g. the generated `AppRouter`) — that requires the docs app to resolve `@rocky/*` workspace imports (a follow-up; see [ADR-0052](/ADR/0052-documentation-architecture)). Until then, this page demonstrates the mechanism on a local type.
