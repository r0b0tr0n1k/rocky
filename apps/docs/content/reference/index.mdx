# Reference

Facts, not narrative. Lookup tables and auto-generated API docs.

- [API Reference (TSDoc)](/reference/api-reference) — generated from TypeScript types
- [Permissions Catalog](/reference/permissions-catalog)
- [Enums Catalog](/reference/enums-catalog)
- [Error Codes](/reference/error-codes)

The API Reference is built with Nextra's `TSDoc` component (`nextra/tsdoc`), which turns `type`/`interface`/`function` source into property + parameter tables — the apex of the repo's NoDrift ideology (docs *are* the types).
